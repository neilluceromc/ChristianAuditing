# Phase 45 — Inventory and Employees Lists Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild `/inventory` and `/employees` as the calm, sticky, zebra-striped lists the owner approved in the
spike: tiles on Inventory, tabs on Employees, three row sizes, rows per page, and Employees bulk actions.

**Architecture:** URL state stays the single source of truth (`url-state.ts`, plus a new `per` param). Shared
presentation moves into `src/components/patterns/` (tiles, tabs, floating bulk bar, sticky list parts) and `Table`
gets a `striped` mode. Pure helpers in `src/lib/` hold every decision that can be unit-tested (tile and tab hrefs,
density parsing, column defaults, bulk-transfer checks). Pages compose them.

**Tech Stack:** Next.js 15 App Router, React 19, Prisma/Postgres, Tailwind v4 (`@theme inline` tokens), vitest (node
env), Playwright + axe.

**Spec:** `docs/superpowers/specs/2026-10-20-inventory-employees-lists-design.md`

## Global Constraints

- **Colours:** tokens only (no hex in components). Light and dark must both work.
- **Dependencies and schema:** no new dependencies and no Prisma schema change. Never run
  `prisma migrate dev/reset/format`.
- **Files:**
  - Keep each file's existing line endings (most are CRLF; edit with the Edit tool or Python `newline=""`).
  - Never read or print any `.env`.
- **Git:**
  - Plain `git add`/`git commit` only. Never stash, checkout, restore, reset, switch, amend or push.
  - Commit trailer exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Checks per task:**
  - `npm run typecheck`, `npm run lint` (`--max-warnings 0`) and `npm test` must pass at the end of every task.
  - **No Playwright and no dev server inside a task.** The controller runs the browser battery once at the end (port
    3100, `--workers=1`, chunks of ≤ 7 files).
- **Copy:**
  - Sentence case; "Rows 1–25 of 900" uses an en dash; "Row size", "Rows per page", "Comfortable", "Compact",
    "Dense".
  - Bulk bar buttons: Inventory "Assign…", "Change status…", "Print labels", "Export", "Clear"; Employees
    "Transfer…", "Export", "Print IT forms", "Clear".
- **List type scale:**
  - Cells: 16 px horizontal padding, 20 px on the first and last cell.
  - Text: primary 13.5 px; second lines 12 px muted.
  - Mono only for tag and serial (12.5 px) and EMP number (12 px). Headers 11 px uppercase.
  - Toolbar controls 36 px tall.
- **Row heights:** body 56 / 48 / 36 px and header 40 / 32 / 32 px, for Comfortable, Compact and Dense.
- **Zebra tokens:** light `--zebra: #f7f8fa; --row-hover: #eef1f5`, dark `--zebra: #1b1f26; --row-hover: #232831`.
- **Rows per page:** `per` ∈ {25, 50, 100}, default 25 (`ENTITY_PAGE_SIZE`), omitted from URLs when 25. Bulk caps use
  `BULK_MAX` (200).

## Review Focus

1. **Junk `per` values** (`per=7`, `per=abc`, `per=100000`, `per=-25`) must fall back to 25 and never throw.
   Test: Task 2.
2. **Old Employees bookmarks** with `kind=…`, `employment=…`, `gaps=1` or `leavers=1` still filter exactly as before.
   The matching tab reads as selected, and a combination that matches no single tab leaves only "All" unselected.
   Test: Task 6.
3. **A bulk transfer** where one ticked person is already in the destination (or the destination is archived) writes
   nothing and names that person. Test: Task 8.
4. **A user who saved Inventory columns before Phase 45** gets Serial number once. If they then hide it, it stays
   hidden. Test: Task 4.
5. **The Need attention tile combined with a search or Category** shows exactly the rows its count promised; tile
   counts equal the row totals they lead to. Test: Task 4 (href/state) and Task 10 (e2e count-equals-total).
